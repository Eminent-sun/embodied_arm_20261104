# 可复用工作流与适用范围

本目录说明已有可复用工具，不宣称已经通过第二设备迁移或干净环境部署。

1. 文件配对检查：fpga/project/software/tools/download_gripper.py不带--download，核对BIT/XSA/ELF/符号及控制台。失效条件为哈希不匹配、缺文件或工具环境不一致；不应忽略失败继续操作。
2. 只读诊断：工程控制台STATUS与现有快照解码工具，查看软件状态/错误；保存DDR不是外部新鲜机械测量。
3. 路径/夹爪工作流：recorded_cycle.py实现显式单次路径、等待和PWM目标；需有效现场标定、初始状态和连续通信。历史记录不自动复用到不同机械臂。
4. 日志统计：metrics/fpga/audit内脚本，保持实测/历史/仿真/待测目标分开；本包提供冻结证据的可迁移复算入口 metrics/scripts/recompute_fpga_metrics.py。

干净环境部署成功率、部署时间与第二设备/第二场景复用结果：待验证。只提供脚本不代表已得到加分项的迁移实验结果。


本文件为合并包的分项工作流，所有路径以提交包根目录为基准；统一入口见 skill/readme.md。
