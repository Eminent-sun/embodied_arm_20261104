## 网页采集

运行 `./scripts/start_dashboard.sh`，浏览器打开 http://127.0.0.1:8080。
首页为采集工作台；原规划界面移动到 `/workbench`。

1. 点击 **开启相机预览**。显示 Gemini 2 原始彩色画面，展开下方可以查看对齐深度。
2. 相机朝向实际桌面，填写摆放/光照说明，选择素材用途，点击 **新建采集场次**。
3. **保存图片** 或按空格：保存干净 PNG、同帧真实深度和相机参数。输入框/下拉框内按空格不会截图。
4. **开始录制**：保存彩色 AVI（MJPEG），每 2 秒尝试选出一张清晰且与上次不同的候选 PNG，同时保存其深度。
   再点 **停止并保存录像**，文件完成封装后网页提供下载链接。
5. 采集结束可关闭相机。关闭相机会先结束录像并关闭当前场次；重新打开后需新建场次。

页面显示现场接收帧率、曝光、粗略清晰度提示、有效深度比例、候选图片数及录像时长。
采集模式不启动 YOLO/MediaPipe，也不向运动控制接口发送任何数据。
需要恢复检测时先关闭网页相机预览，再运行原 `start_vision.sh`；项目的 Orbbec 相机入口使用设备锁防止同时占用。
GPU 继续用于之后的 YOLO11n 推理/训练；原始采集、JPEG 与录像编码在 CPU 上完成，无需占用 GPU/NPU。

## 怎样组织素材

- 对象：螺丝刀、钳子、剪刀/蓝色剪切工具、镊子，类别编号保持 0–3。
  PCB 尚未训练。页面的工具勾选只表示预期出现类别，**不是图像标注**。
- 建议先录 3–5 段、每段 30–60 秒：单类工具、七件混合、不同朝向、少量交叠、工作区边缘、不同照明。
  移动后把手移出并停留几秒，让细镊子和金属反光边缘清晰。
- 补充空桌、笔、键盘等背景/干扰物。可以将截图标为“漏检、类别混淆、误检背景、遮挡”等待审核难例。
- 分别重新摆放并录制验证、独立测试场次。同一段录像的相邻帧及其增强副本不能跨集合。
  即使新建了场次，若画面与之前近乎一样也不算独立测试，需要在组装数据集时跨场次查重。
- 同一场次的用途创建后不可更改。新建下一场次必须先停止录像。
  `exclude` 用于测试采集链路，不可加入训练、验证、测试指标。

## 保存格式与限制

目录：`datasets/site_tools/web_sessions/table_日期_时间_随机ID/`。

| 文件 | 内容 |
|---|---|
| session.json | 场次/group_id、用途、场景说明、类别编号、候选图片及录像清单、待标注状态 |
| images/000001.png | 无检测框的原始彩色图 |
| depth/000001.npz | 与 PNG 同帧、已对齐的 `depth_m`，float32，米 |
| metadata/000001.json | 相机序列号、工厂内参/畸变、帧号、主机接收/设备时间戳、质量指标、图像哈希、用途、候选来源 |
| videos/0001.avi | 干净彩色视频，MJPEG，名义播放帧率 30 FPS |
| videos/0001.jsonl | 每个实际写入视频帧的索引、帧号和时间戳；实际采集速率以此及报告为准 |

深度随 PNG 截图/候选帧保存，**并非完整逐帧 RGB-D 录像**。
视频播放采用固定名义帧率；若采集或存储变慢，实际拍摄间隔应按时间戳读取，不假定严格 30 Hz。
主机时间是 SDK 接收时刻，不声称等同于曝光时刻。

单段录像上限 180 秒，单场次上限 1000 张候选图；剩余空间不足 2 GiB 会停止写入。
不会自动删除用户素材。相机异常或关闭预览时会结束正在写入的录像；强制断电/kill -9 的文件仍可能不完整，
未完成封装的视频不得直接视为可靠训练源。网页重启后历史清单可保留其未完成状态供检查。

自动筛选跳过近黑图、粗略模糊图和相似图；这些只是候选筛选规则，不证明工具完整或准确可标注。
手动截图保留清晰度提示但不进行相似度筛选，近黑图和过期帧仍拒绝保存。
收藏的素材统一 `annotation_status: unlabelled`，没有用旧检测器输出冒充人工真值。

## 桌面拾取规划

`config/planning.json` 已设 `task_kind: tabletop_pickup`，但 `validated` 仍为 false。
保持真实外参、固定安装位、夹爪/TCP、模型指纹、工作区与抓取方向审核门槛。
没有检测到手不能作为安全证明；手存在/刚消失或状态未知仍阻止新的实测拾取请求。
工具目标 ID、深度质量与坐标新鲜度检查不变。

流程为接近 → 下探抓取 → 闭爪与有效夹持反馈 → 抬升并保持。
三段轨迹预览不会上传/执行，不包含自动松爪、递送或放置；实物反馈与真实控制器仍未验收。

实测配置完成后命令行不再需要 `--zone` 或 `--hand-track-id`：

```bash
.venv-vision/bin/python scripts/make_plan_request.py \
  --track-id 4 --profile pliers_flat --output runtime/planning/pickup_live.json
./scripts/plan_task.sh --request runtime/planning/pickup_live.json \
  --output runtime/planning/pickup_live_result.json
```

## 本轮验证

- 57 项单元/通信测试通过，新增同帧 PNG/深度、录像帧数与逐帧时间戳、关闭预览封装录像、
