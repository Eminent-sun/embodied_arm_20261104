## 尚未解决的情况

仍有 13 张测试图不完全正确：镊子过细、部分出画或预测框偏宽造成 IoU 不达标，以及支架/背景线条的少量误检。
`remaining_failures.json` 保存具体帧。未为改善测试数字而改测试标签、调高阈值隐藏误检或把测试图加入训练。

**这些指标只适用于本次留出的相关拍摄场次。** 三个场次使用同一批工具、同一时段及相同黑板/浅色砖面背景；
虽然整场留出，仍不能推断陌生工具、不同工作台、杂乱遮挡、收纳盒或手持场景的效果，更不是抓取成功率。
固定相机和真实桌面后仍需现场验证。相机未固定、有效基座外参和真实夹爪/TCP未完成，检测框不是抓取位姿。
现有真实深度、时序过滤、坐标有效性与人工确认门槛保持有效；本轮不输出可执行的基座运动目标。

## 复现与回退

训练入口 `scripts/train_tools.py`，数据构建 `scripts/prepare_site_tools_v4.py`，固定阈值评估 `scripts/evaluate_site_tools_v4.py`。
原始参数在 `runtime/training/tools_site_v4_run/args.yaml`，日志、results.csv、best/last 权重均保留。
使用新实验名字复训，初始化应显式指定归档 v3，而不是已更新的默认文件。

```bash
.venv-rocm/bin/python scripts/train_tools.py \
  --data datasets/tools_site_v4/data.yaml --device 0 --epochs 25 --patience 8 \
  --batch 16 --imgsz 640 --workers 4 --name tools_site_v4_repeat \
  --model models/archive/tabletop_v3_before_site_v4/tools_yolo11n.pt \
  --optimizer AdamW --lr0 0.0006 --mosaic 0.25 --degrees 20
```

需要对比旧版时，在视觉启动命令显式指定 `--model models/archive/tabletop_v3_before_site_v4/tools_yolo11n.pt`。
本轮未恢复持续推理，用户启动检测时默认加载 v4。
