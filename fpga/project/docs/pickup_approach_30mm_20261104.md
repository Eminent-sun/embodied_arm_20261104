# RUNPATH v3：高位准备、下移拾取

本次仅更新电脑路径模块。用户已确认准备位 Pitch=-10°、下降后恢复0°；5秒等待放在下降完成之后。递送、松爪和返回沿用此前实物已跑通的路线。

## 完整顺序

| 阶段 | 动作 |
|---|---|
| 启动 | 当前有效标定的 INITIAL_HOLD 连续停稳；检查首段，夹爪完全打开到1110 μs |
| 运动1 | 到高位准备点：`180 0 190 0 -10 0`，比原拾取点高30 mm |
| 运动2 | 下移到原拾取点：`180 0 160 0 0 0`，Pitch恢复0°，夹爪保持打开 |
| 拾取等待 | 确认下降执行完成、位置速度到位，再固定等待5秒 |
| 闭爪 | 再次确认连续停稳，闭合到1490 μs，等待PWM渐变完成 |
| 运动3 | 保持拾取姿态抬升10 mm：`180 0 170 0 0 0` |
| 运动4 | 到递送点：`180 -150 170 -60 -90 0` |
| 递送 | 到位后等3秒，完全打开到1110 μs；PWM渐变完成再等2秒 |
| 运动5 | 保持递送姿态抬升30 mm：`180 -150 200 -60 -90 0` |
| 运动6 | GOHOME，回当前SAVEINITIAL保存的初始位，保持INITIAL_HOLD和夹爪打开 |

坐标顺序为X/Y/Z/Roll/Pitch/Yaw，位置mm、角度°。高位没有额外5秒等待；5秒从下降到原拾取点、连续确认停稳后开始计算。

原姿态全零的`180 0 190 0 0 0`在当前限制下被实际ARM规划器拒绝。采用已获用户确认的准备位Pitch=-10°；保持原有限位、方向、速度和加速度设置。

仍使用已有五次曲线关节插值，每段末尾停稳；下降段不是严格的末端直线，离线逐帧测得横向偏差小于1 mm，Z连续下降。这里的位置与高度是模型Link6原点，不包含夹爪外形。

## 当前窗口怎样使用

1. 若上一轮已完成、仍在原ARM>窗口，保持窗口开启。
2. 输入`STATUS`，确认`INITIAL_HOLD`、`error=0`、`enabled_mask=0x3f`、`calibrated_mask=0x3f`、`model_initial_saved=True`，并确认实物停稳。
3. 放好物品，手离开运动范围，显式输入`RUNPATH`。应首先显示：

```text
RUNPATH v3：6 段路线；先到 Z=190 mm、Pitch=-10°，下移到 Z=160 mm、Pitch=0°，停稳等 5 秒再闭爪。
```

4. 依次会显示“前往拾取准备位（抬高30 mm）”“下移到拾取点”，之后才是5秒倒计时和闭爪。

每次RUNPATH都会重新载入当前路径模块，因此本次无需关窗口、重新烧录或仅为更新重新标定。已经启动的旧一轮不会中途换路线；等它正常完成再运行新一轮。旧窗口的PATHINFO可能仍显示内存中的上一版说明，以新一轮RUNPATH的v3开头和阶段输出为准；新开控制台会直接显示最新说明。

若不是INITIAL_HOLD或有故障，先处理实际状态，不直接启动。电机断电、重新下载或零点关系变化后，仍须按总说明重新建立有效实物HOME标定。运行中Ctrl+C请求STOP，可能释放保持力矩，需有承托。

## 验证

104项电脑脚本测试，另用实际交付ARM ELF在虚拟电机/PWM环境执行完整6段流程，检查下降前后顺序、下降单调性、横向偏差、关节/电机限位、五次曲线、离散速度和加速度。回归覆盖下降未到位或规划被拒绝时不得开始5秒计时/闭爪，以及原固定等待抗反馈波动逻辑。

报告为`software/reports/recorded_cycle_arm_path.json`、`software/reports/recorded_start_reproduction.json`和`reports/python_tests.log`。这是离线验证；本次未连接、下载或驱动实物，新准备点和下降段仍需现场观察。既有正常路线备份于`history/before_pick_approach_30mm_20261104/`。
