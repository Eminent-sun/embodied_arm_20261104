# 人机协同具身机械臂设计报告（现有证据汇编）

日期2026-11-04；主工程robstride_arm_gripper_20261104。

## 背景与任务

面向桌面级物品拾取、递送和返回操作，采用PC交互/流程控制、Zynq PS运动学与规划、PL CAN执行与PWM夹爪的分工。当前材料可证明控制系统实现与部分实机路径记录；端侧 AI 材料现已并入 host/ 与 AIPC 分册；物品级联合闭环成功判定仍需专门证据。

## 架构与创新点的证据边界

具体架构与接口见docs。可据源码说明的工程特点包括运动学/轨迹与IO分层、CAN事务统一所有权、按轴反馈检查、显式标定/状态许可、独立AXI PWM外设，以及故障后不自动重放动作。这是实现特性，不据此宣称已优于全部既有方案；相关同条件对比实验尚缺。

## AI PC端

FPGA 侧保留 Python 交互、任务编排、JTAG 通信和日志。AIPC 侧另提供模型权重、推理/后端、精度测试集与 ROCm 记录，详见 aipc_report.md、../host/model/model.md。两者测试设备与传输协议不同，联合关系见 ../docs/interface.md。

## FPGA/Zynq端

PL包含自定义AXI运动邮箱、CAN事务/接收/协议模块与单路PWM，PS包含URDF/Pieper运动学、轨迹生成、执行、标定与状态机。源码在完整工程candidate和software目录。硬件承担确定时序输出、CAN协议状态与接口扩展，超出普通转接板功能；其物理抖动/延迟的量化优势仍须补示波器或逻辑分析仪测量。

已有11月4日布线报告：LUT 9814/17600（55.76%），FF 8576/35200（24.36%），BRAM 1.5/60（2.50%），DSP 0/80，Slice3438/4400（78.14%）；WNS+0.218ns、WHS+0.037ns。保留IO约束/CDC/reset告警，不能宣称所有外部时序和CDC已验收。

## 两端协同

当前PC→XSCT/JTAG→DDR→PS→AXI邮箱→CAN/PWM；反向传状态及错误。CRC和单调序号用于命令完整性与会话约束，PS周期性服务心跳并控制执行许可。具体数据布局见docs/interface。现有材料缺PC-PS时钟同步验证、链路RTT/吞吐/超时率和端到端感知至实际物理响应时间，相关指标实测栏留空。

## 日志结果

开发日志12次路径启动：8完成、2拒绝保持、1中止、1缺结束事件，跨路径/标定修订，不作为正式固定条件的抓取闭环成功率。8次完成路径耗时84.50–92.438s；95组保持位快照×6轴共570样本，相对控制目标汇总RMSE=0.000130001rad。该误差仅为挑选后保持状态的电机反馈读数，不是全轨迹误差或外部物理定位精度。

旧参数调试版35次CAN读取均有匹配回复与原始捕获校验；不能替代当前PC-FPGA通信评测。历史PWM仿真246项断言通过及解析逆解1012目标通过属于离线证据。本包没有把它们转写为实机闭环成绩。完整数值、分位数与每项原始证据见metrics/fpga/audit/report.md及metrics.csv。

## 失败与风险的真实记录

7个会话保存10份故障快照，其中4份停止未确认，部分为同一锁存事件重复观测。不能把它们解释成独立故障计数、MTBF或安全状态成功率。路径规划拒绝与保持、通信故障、异常恢复均保留原始记录。无物品/力反馈，PWM目标到达不证明已经抓紧；机械标定、负载与供电条件仍需完整冻结。
